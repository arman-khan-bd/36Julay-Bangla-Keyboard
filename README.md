# 36Julay | ৩৬জুলাই বাংলা কীবোর্ড (36Julay Bangla Keyboard in Rust)
### BDS 1738:2018 / BDS 1935:2018 / BDS 1520:2018 Standard Implementation for Windows + Linux (All Distros)

A ultra-fast, modern, memory-safe Bengali typing keyboard software written in **pure Rust**. Designed from the ground up according to the official **বিজয় নির্দেশিকা (Bijoy Bangla Typing Nirdeshika)** and Bangladesh national keyboard standards.

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- **শীর্ষ ফ্লোটিং কীবোর্ড বার (Top Floating Bar - Image 1)**:
  - স্ক্রিনের শীর্ষে সুন্দর অ্যাক্রিলিক/গ্লাস ডিজাইন করা ফ্লোটিং বার।
  - সোনালী 'অ' লোগো, লেআউট সিলেক্টর (English, বিজয় ৩৬জুলাই, বিজয় ক্লাসিক, অভ্র ফোনেটিক)।
  - এক ক্লিকে ভার্চুয়াল কীবোর্ড ওপেন, কনভার্টার টুল, সেটিংস এবং হেল্প গাইড।
- **প্রিভিউ উইন্ডো ও সদৃশ শব্দ পরামর্শ (Preview Window - Image 2)**:
  - টাইপ করার সময় রিয়েল-টাইমে সদৃশ শব্দের তালিকা (যেমন `sOnar` টাইপ করলে `সোনার`, `সনার`, `শোনার`, `শোণার`) প্রদর্শিত হয়।
  - কীবোর্ডের `1`–`4` বা `Space`/`Enter` চেপে সাথে সাথে সঠিক বানান সিলেক্ট করা যায়।
  - পিন বাটন (`📌`) চেপে যেকোনো সুবিধাজনক স্থানে রাখা যায়।
- **অভ্র ⇄ ৩৬জুলাই (বিজয়) কনভার্টার (Avro ⇄ 36July Converter)**:
  - অভ্র বা ইউনিকোড থেকে সরাসরি ৩৬জুলাই (বিজয় সুতন্বীএমজে) ফন্টে দ্বিমুখী রূপান্তর।
  - অভ্র ফোনেটিক ইংরেজি ইনপুট থেকে বাংলা ইউনিকোড ও বিজয় ক্লাসিক রূপান্তর।
- **সহজ ইনস্টলার (One-Click Installers)**:
  - **Windows**: `install-windows.bat` বা `install-windows.ps1` চালিয়ে এক ক্লিকে ইনস্টল, ডেস্কটপ শর্টকাট ও অটোস্টার্ট।
  - **Linux**: `./install-linux.sh` চালিয়ে Ubuntu/Debian/Fedora/Arch এ IBus সহ পূর্ণাঙ্গ ইনস্টল।
- **দ্বিমুখী প্ল্যাটফর্ম সাপোর্ট (Windows + Linux All Distros)**:
  - **Windows**: নেটিভ `WH_KEYBOARD_LL` লো-লেভেল হুক এবং `SendInput` ইউনিকোড ইনজেকশন। যেকোনো অ্যাপে (MS Word, Notepad, Chrome, VS Code, ইত্যাদি) সরাসরি বাংলা টাইপ করা যায়।
  - **Linux (সব ডিস্ট্রো)**: প্রমিত **IBus Engine** জেনারেটর (Ubuntu, Debian, Fedora, Arch, openSUSE, Pop!_OS ইত্যাদি সব লিনাক্স ডিস্ট্রোতে Wayland ও X11 উভয় পরিবেশেই কাজ করে), এবং `uinput` ভার্চুয়াল কীবোর্ড ড্রাইভার।
- **তিনটি টাইপিং মোড (Three Typing Modes)**:
  - **বিজয় ইউনিকোড (Bijoy Unicode)**: `Ctrl + Alt + V` (ইন্টারনেট, ওয়েব ব্রাউজার, চ্যাট, আধুনিক সব সফটওয়্যারের জন্য প্রমিত ইউনিকোড)।
  - **বিজয় ক্লাসিক (Bijoy Classic / SutonnyMJ)**: `Ctrl + Alt + B` (ফটোশপ, ইলাস্ট্রেটর, ইনডিজাইন ও সুতন্বীএমজে ফন্টে টাইপিংয়ের জন্য ANSI এনকোডিং)।
  - **ইংরেজি (English)**: `Ctrl + Alt + E` (স্বাভাবিক ইংরেজি টাইপিং)।
  - **কুইক টগল (Quick Toggle)**: `F12` চেপে সহজে ইংরেজি ও শেষ ব্যবহৃত বিজয় মোডের মধ্যে পরিবর্তন।
- **বিজয় টাইপিং নির্দেশিকার শতভাগ নিয়মাবলী (Complete Typing Rules)**:
  - স্বরবর্ণ (`F`=অ, `gf`=আ, `gd`=ই, `gD`=ঈ, `gs`=উ, `gS`=ঊ, `ga`=ঋ, `gc`=এ, `gC`=ঐ, `x`=ও, `gX`=ঔ)।
  - কার চিহ্ন (`f`=া, `d`=ি, `D`=ী, `s`=ু, `S`=ূ, `a`=ৃ, `c`=ে, `C`=ৈ, `X`=ৌ)।
  - ভিজ্যুয়াল প্রি-কার (`d`+`k` = `তি`, `c`+`k` = `তে`) এবং লজিক্যাল কার টাইপিং।
  - ও-কার ও ঔ-কার কম্বিনেশন (`c` + বর্ণ + `f` = `তো`, `c` + বর্ণ + `X` = `তৌ`)।
  - ২০০+ যুক্তাক্ষর (হসন্ত `g` লিঙ্ক বোতাম দিয়ে: যেমন `j`+`g`+`k`=ক্ত, `j`+`g`+`N`=ক্ষ, `u`+`g`+`I`=জ্ঞ, `i`+`g`+`m`=হ্ম)।
  - রেফ (`A` চেপে ব্যঞ্জনবর্ণ বা `v`+`g`+বর্ণ = র্ক) এবং ফলা (`z`=্র র-ফলা, `Z`=্য য-ফলা)।
  - ২০২৪ সংস্করণের প্রাচীন মুদ্রা ও অসমীয়া বর্ণ (`g1`–`g8` আনা/গণ্ডা, `g,`=ৰ, `g.`=ৱ, `g#`=ঽ, `gG`=॥)।
- **দ্বিমুখী কনভার্টার (SutonnyMJ ⇄ Unicode Converter)**:
  - পুরনো সুতন্বীএমজে ফন্টের লেখা ইউনিকোডে রূপান্তর এবং ইউনিকোড থেকে সুতন্বীএমজেতে রূপান্তর।
- **মডার্ন কন্ট্রোল সেন্টার ও ভার্চুয়াল কীবোর্ড (Web & Desktop GUI)**:
  - নির্দেশিকার ২য় পৃষ্ঠার মতো ৪-কোণা ভার্চুয়াল বিজয় কীবোর্ড (স্বাভাবিক, শিফট, লিঙ্ক ও ইংরেজি লেবেল সহ)।
  - রিয়েল-টাইম স্ক্র্যাচপ্যাড ও ক্লিপবোর্ড কপি সুবিধা।
  - সার্চযোগ্য যুক্তাক্ষর নির্দেশিকা ডিকশনারি।

## 🚀 চালানো ও ব্যবহারের নিয়ম (Usage)

### ১. ডেক্সটপ অ্যাপ ও সিস্টেম-ওয়াইড টাইপিং ড্রাইভার চালানো:
```bash
cargo run -p bijoy-app
# অথবা ইনস্টলার দিয়ে ইনস্টল করে ডেস্কটপ আইকনে ডাবল ক্লিক করুন
.\install-windows.bat
```
- এটি ১০০% নেটিভ উইন্ডোজ সফটওয়্যার (Win32 GUI) হিসেবে রান করবে — কোনো ব্রাউজার খুলবে না।
- স্ক্রিনের শীর্ষে ফ্লোটিং কীবোর্ড বার এবং প্রিভিউ উইন্ডো দেখা যাবে।
- যেকোনো উইন্ডোজ অ্যাপ্লিকেশনে (Notepad, MS Word, Chrome, ইত্যাদি) সরাসরি বাংলা টাইপ করতে পারবেন।
- কীবোর্ডের `Ctrl+Alt+V`, `Ctrl+Alt+B`, `Ctrl+Alt+E`, অথবা `F12` দিয়ে টাইপিং মোড বদলান।
- ব্রাউজার মোড প্রয়োজন হলে `cargo run -p bijoy-app -- --web` দিয়ে চালানো যাবে।

### ২. সিএলআই ও টার্মিনাল REPL:
```bash
# ইন্টারেক্টিভ টার্মিনাল টাইপিং REPL
cargo run -p bijoy-cli -- repl

# কীবোর্ড লেআউট চার্ট ও যুক্তাক্ষর তালিকা দেখুন
cargo run -p bijoy-cli -- layout

# টেক্সট কনভার্সন (SutonnyMJ থেকে Unicode)
cargo run -p bijoy-cli -- convert "wWwRUvj evsjv‡`k" --to-unicode

# টেক্সট কনভার্সন (Unicode থেকে SutonnyMJ)
cargo run -p bijoy-cli -- convert "আমার সোনার বাংলা" --to-classic

# পুরো ফাইল কনভার্সন
cargo run -p bijoy-cli -- convert -i input.txt -o output.txt --to-unicode
```

### ৩. লিনাক্স (সব ডিস্ট্রোতে IBus সেটআপ):
```bash
# IBus কম্পোনেন্ট ফাইল ইনস্টল করতে:
cargo run -p bijoy-cli -- linux install-ibus

# এরপর IBus রিস্টার্ট করুন:
ibus restart

# সিস্টেমের Settings -> Keyboard -> Input Sources এ গিয়ে যোগ করুন:
# "Bangla (Bijoy Keyboard BDS 1738)"
```
